## 2026-09-26 描画に wterm を使い、tmux にサーバーからつなぐ

- Claude Code に複数行の指示を書くため。ソフトキーボードには Ctrl が無いので、キーバーの Ctrl を押してからの Enter でも送れるようにした

## 2026-09-26 シェルの上のスワイプは tmux のコピーモードで動かす（重ねた履歴表示はやめた）

- 最初は tmux の履歴を色付きで取り、2つ目の端末（libghostty のエンジン）に流して重ね、ブラウザのスクロールで動かした
- 切り替わりがはっきり見えて、画面がそのまま動く感覚にならなかったのでやめた。サーバーから tmux のコピーモードを操作し、指に合わせて1行ずつスクロールする方法に変えた
- ホイールで送る方法は、1回で5行飛ぶうえ tmux の `mouse` が off だと効かないため使わない
- 根拠: 73542ae、8e91131

## 2026-09-26 画像は、パスだけを貼り付けとして送り、読めない形式は JPEG にする

- Claude Code は画像のパスだけの貼り付けを添付として扱い、文章と混ざると添付にならない。そのため画像のパスを1枚ずつ貼り付けてから文章と Enter を送る
- HEIC と JPG を一緒に送ると HEIC がパスの文字のまま残って画像が欠けていたので、読めない形式は ffmpeg で JPEG に変換し、失敗した画像があれば送らない
- パスを入力欄に入れるのをやめ、サムネイルの添付欄にした
- 根拠: 7dd3dea、97f2966

## 2026-09-27 LAN から HTTPS で直接つなげるようにする

- Tailscale の中継（127.0.0.1）はそのままに、LAN 向けに自分で署名した証明書で HTTPS も待ち受ける。トークンを平文で流さないためと、スマホのクリップボードの機能を使えるようにするため
- 根拠: 896879b、README

## 2026-09-27 Cookie は SameSite=Lax にする

- Strict だと、チャットなど他のアプリから開いたリンクや、証明書の警告から進んだ直後に Cookie が送られず、ログインを求められていた（Pixel の Chrome で確認）
- Lax でも別のサイトからの POST には Cookie が付かず、WebSocket は Origin を確かめるので、勝手に操作はされない（通しのテストで確認）
- 根拠: 9d3acc9

## 2026-09-27 レビュー（Codex・Fable）の指摘で、入力と安全の穴をふさぐ

- 貼り付けの中に仕込んだ制御文字でブラケットペーストから抜け出し、コマンドを実行できていたので、中の ESC を取り除く（534fb6f）
- 切断中の送信で文章と画像が消えていた、送信中に足した画像が消えていた、などの取りこぼしを直す（a2a0b3b、75b166c、b180604）
- 画面の修飾キーを物理キーボードの特殊キーにも効かせる。効かずに残って次の文字に付いていた（dfcc84f、ebf5dc5、e8bc9ee）
- タブの問い合わせを、結果が変わらない間は間隔を広げ、裏に回っている間は止める（b73ced4、25570d9）
- ウィンドウの名前の # を tmux の書式として展開させない（103b66e）
- ログイン用のトークンを tmux の中のシェルの環境に渡さない。前の palmterm が残したものも消す（8132fb3、9fe5a78）
- 上げたファイルを返すときに、スクリプトとして動かないようにする（5eb2160）
- 不完全な接続の居座りを時間切れで切る。端末の接続は切らない（5874176、f949ce9）
- トークンのファイルの権限を読むときにも直し、比べ方を長さに左右されないものにする（4be474f）

## 2026-09-27 LAN の証明書・待ち受けの範囲・Cookie の中身を変える（仮決定）

- 証明書を作り直すとき前のアドレスも引き継ぐ。家と職場を行き来するたびに警告を越える必要があったため（8c5f451）
- `-lan :7682` はすべてのネットワークで待ち受け、IPv6 のグローバルアドレスなど LAN 以外にも開いていた。プライベート・リンクローカル・Tailscale の IPv4 アドレスごとに待ち受けるよう変えた（e08d509、a1f7bce）。1つ失敗しても全体は止めない（de8430f）
- Cookie はポートで分けられず、同じホストの別のサービスにも送られる。そこから漏れても新しい端末でログインできないよう、トークンそのものではなく計算した値を入れる（7fc0942）
- いずれも commit に「仮決定」とある。本人の確認の記録は見当たらない

## 2026-09-27 サービスとして動かすときは、tmux をサービスの外で起動する

- Fedora などの tmux は、ペインのシェルを tmux のサーバーと同じ単位に入れる。palmterm のサービスが tmux を起動すると、サービスを止めたときにペインが全部止められ、セッションが消えていた。KillMode=process でも防げないことを確かめた
- つなぐ先のセッションが無いときだけ、`systemd-run --user --scope` で外にセッションを作ってからつなぐ
- 根拠: 140d14b、c8d234c

## 2026-10-14 ログアウトと端末ごとの取り消し

SPEC.md の「予定」にあったもの。本人が寝ている間に作ったので、作り方は仮決定（本人の確認待ち）。

- Cookie の値を、トークンから計算した1つの値から、ログインごとのランダムな値に変えた。サーバーは値の SHA-256 だけを `devices.json` に持つ。値が1つだと、1台だけ締め出すことができないため
- 記録はトークンと同じ `~/.config/palmterm/` に置き、トークンから計算した値を一緒に書く。トークンが変わっていたら記録を全部捨てる。今までの「トークンを変えれば全端末を締め出せる」を保つため
- 前の形の Cookie（トークンから計算した値）は通さない。通すと、漏れた前の Cookie はトークンを変えるまで取り消せないまま残るため。代わりに、前から使っていた端末は一度ログインし直す（`palmterm url` の QR で開き直す）
- 最後に使った時刻は、リクエストのたびではなく1時間に1回までしかファイルに書かない
- 取り消したら、その端末の開いている WebSocket をすぐ切る（1008）。画面は 1008 で切られたとき、またはつなぎ直しが 401 で断られたときは、つなぎ直しを続けずに読み込み直し、ログインし直す案内を出す
- 一覧は、新しいボタンを増やさず、tmux ボタンのパネルの「その他」の行に置いた。たまにしか使わないため
- PC からの操作用のコマンド（`palmterm devices` など）は作っていない。なくしたスマホは、PC のブラウザで `palmterm url` の URL を開いて取り消せるため

## 2026-10-14 ログイン中の端末に名前を付ける

- 本人の要望。User-Agent から作る名前（「iPhone · Safari」）だけでは、同じ種類の端末を見分けられないため
- 名前はブラウザではなくサーバーの記録に持つ。なくした端末を別の端末から見分けて取り消すのが目的なので、どの端末からも同じ名前が見えないといけない
- 付け方は tmux のタブの名前と同じにした（名前を押すと入力欄になり、Enter か外をタップで決定、Esc でやめる、空で自動の名前に戻す）。押せることが分かりにくいので、一覧の上に一行の案内を出す
- 自動の名前は消さずに下の行に添える。付けた名前が間違っていても、本当は何の端末かが分かるように


## 2026-10-15 `palmterm -version` で版を出す

- いま動いている palmterm がどの版かをコマンドで確かめるため（課題 0001）
- 版は `-ldflags "-X main.version=..."` で埋め込み、`make` では `git describe --tags --always --dirty` を使う。タグがまだ無いので、今は commit のハッシュ（変更があれば `-dirty` 付き）が入る
- `make` は Go と画面のファイルが変わったときだけ作り直すので、commit しただけ（ファイルは同じ）では実行ファイルの版は前のままになる。作り直すには `make -B`
