# 設定画面のテーマの設定項目もフォントみたいにリストにして、色見本付きで選びたい

## 目的
設定画面のテーマの設定項目もフォントみたいにリストにして、色見本付きで選びたい

## 完了の条件
- [ ] 確かめる手順: 設定画面の「テーマ」の行に、横並びのボタンの代わりに「一覧」がある。押すとテーマの一覧が開く。2列の画面では右の列に出て、押した「一覧」に印が付く。小さい画面では設定画面に代わって開き、「閉じる」で設定画面に戻る
- [ ] 確かめる手順: 一覧には組み込みのテーマ、その後ろに [themes.名前] の自分のテーマが並ぶ。各行に名前と色見本（テーマの背景の上に文字の色で書いた見本の文字と、端末の16色の四角）が出て、今のテーマの行に印が付く
- [ ] 確かめる手順: 行を押すと、読み込み直さずにすぐ見本どおりの色に変わり、[theme] の name が書き換わり、印がその行に移る。一覧は開いたままで続けて見比べられる
- [ ] 通しのテストで上を確かめ、make test が通る
