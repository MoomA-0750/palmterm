## メモ
- 書き戻しの行を見つけられない書き方（インラインのテーブル、ドットの付いた書き方、複数行の文字列）は、最初は書き換えたあとに TOML として読めなくなって気づく形だった。複数行の文字列 `"""…"""` では先頭の `""` を値と取り違えて壊れた文章を作っていた（保存前の確かめで止まっていた）ので、値の後ろはコメントか行の終わりだけに限った
- 通しのテストで tmux ボタンの文字の色で accent を確かめようとしたが、パネルを開いている間はボタンの色が変わるので、`--accent` の値で確かめる形にした

## 結果
### したこと
- サーバーに `POST /api/config/appearance`（ログインした端末だけ）を足した（configwrite.go）。`{"theme": 名前}` で `[theme]` の `name`、`{"font": 名前}` で `[font]` の `file = "fonts/名前"` を書き換え、`{"font": ""}` で `file` の行を消す。応答は `/api/config` と同じ形で、画面はそれをすぐ当てる
- 書き戻しは文章のまま該当の1行だけを書き換える（行の後ろのコメント・CRLF・権限もそのまま。行が無ければテーブルの最後の項目の後ろ、テーブルが無ければファイルの最後に足す。ファイルが無ければ `version = 1` と一緒に作る）。書き換える前後を読み比べて、変わったのがその所だけのときだけ、一時ファイル経由で保存する。リンクの設定ファイルは先を書き換える
- 書き間違いがあって読めない設定ファイル、書き換える行を見つけられない書き方は書かずに 409 で理由を返し、画面は知らせて色もフォントも変えない
- 画面: tmux パネルに「テーマ」の行（既定・明るい・Solarized 暗・Solarized 明。今のものに印）。フォントはパネルの「フォント」で開く一覧の各行に「使う」、先頭に「既定のフォント」（`file` を消す）を足した。選び直したときは前に配ったフォントを外してから当てる
- SPEC.md に「画面でテーマとフォントを選ぶ」の節（確定）、README（日英）・config.example.toml に使い方、docs/decisions.md に理由を書いた

### 本人に見てほしい点
- フォントを選ぶ所は、tmux パネルの行ではなく、パネルの「フォント」で開く一覧の「使う」にした（足したフォントが増えると行に収まらないため）。「tmux パネルから選ぶ」の読み方として合っているか
- テーマのボタンは押してもパネルを閉じない（見比べやすいように）。テーマの表示名は日本語で「既定・明るい・Solarized 暗・Solarized 明」にした
- フォントを選んでも `family` の行は残す（`file` が優先される）。「既定のフォント」は `file` の行を消すだけなので、`family` を書いていればそれに戻る
- `[theme]` を `theme = { … }` や `theme.name = …` で書いている人は、画面から選べず「手で直して」と出る
- 実機で確かめるには `make install` して palmterm を再起動してから（スマホで tmux パネル →「テーマ」、「フォント」→「使う」）
