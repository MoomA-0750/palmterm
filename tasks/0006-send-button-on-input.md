# 送信ボタンを、入力したときだけ出す

## 目的
送信ボタンを、入力したときだけ出す

## 完了の条件
- [x] 確かめる手順: テキストボックスが空で添付もないときは送信ボタンが出ず、テキストボックスがその分だけ横に伸びている
- [x] 確かめる手順: テキストボックスに1文字入れると送信ボタンが出て、全部消すとまた消える
- [x] 確かめる手順: 文字が空でも画像を1枚添付すると送信ボタンが出て、× で外すと消える
- [x] 確かめる手順: 送信ボタンで送ってテキストボックスが空になると、送信ボタンが消える
- [x] 確かめる手順: 空のまま Ctrl+Enter（またはキーバーの Ctrl→Enter）を押すと、今と同じく Enter だけを端末に送る
- [x] 上の動きを通しのテスト（web/e2e/app.test.ts）で確かめ、make test が通る

## メモ
- `hidden` 属性だけでは `#inputbar button { display: grid }` に負けて消えないので、`#inputbar button[hidden] { display: none }` を足した

## 結果
- したこと: テキストボックスが空で添付も無いときは送信ボタンを隠す（web/src/main.ts の `updateSendButton`）。テキストボックスの中身が変わるたび（入力・送信・貼り付け・コピーモードからの挿入）と、添付欄が変わるたびに出し分ける。最初の表示でちらつかないよう index.html でも最初は `hidden` にした
- 確かめたこと: 通しのテスト「送信ボタンは、文字か添付があるときだけ出す。空の Ctrl+Enter は Enter だけを送る」を足した。空で隠れていること、テキストボックスがボタンの幅＋4px 伸びること、1文字で出て消すと隠れること、画像だけで出て × で隠れること、送って空になると隠れること、空の Ctrl+Enter とキーバーの Ctrl → Enter が `\r` だけを送ることを確かめる。`make test` は Go・単体・通しのテストとも通った
- 本人が見るべき点: 実機（スマホ）で、文字を打ち始めたときにボタンが出てテキストボックスが縮む動きが気にならないか。SPEC の項目は「仮」で置いたので、実機で確かめたら「確定」にしてよい
