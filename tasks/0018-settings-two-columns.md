# 大きい画面では設定画面を2列にする

## 目的
大きい画面では設定画面を2列にする

## 完了の条件

- [x] 確かめる手順: 小さい画面では今までどおり1列で、一覧は設定画面に代わって出て、閉じると設定画面に戻る
- [x] 通しのテストで上の2つを確かめ、make test が通る

## メモ

## 結果
- したこと
  - web/src/settings.ts: 設定画面を左（`#settings-main`：帯と設定の行）と右（`#settings-side`）に分けた。板を浮かせる大きさの画面では開くときに `#devices` と `#fonts` を右の列に移し、開いた直後は「ログイン中の端末」を出す。左の「一覧」で押した方を右に出し、その「一覧」に印（`.on`）を付ける。設定画面を閉じると右の一覧も隠す。小さい画面では一覧を body に戻して今までどおり上に重ねる。開いている間に大きさが変わったらその場で切り替える
  - web/src/sheets.ts: 別の板の中に入った板は「一番上の板」と見なさない（幕・Esc で設定画面ごと閉じる）
  - web/src/style.css: 2列の設定画面は幅 min(900px, 画面の9割)。右の一覧は浮かせる指定を外して列いっぱいに出し、「閉じる」を隠す
  - テスト: 単体テスト「大きい画面では2列にし、…」を足し、通しのテスト「大きい画面の板」の2つを2列・1列に合わせて書き直した
  - SPEC.md「設定画面」「板の出し方」と docs/decisions.md を今の動きに直した
- 確かめたこと
  - `make test` が通った（Go、単体 140、通し 37）
  - 通しのテストで、1024×768 では板の幅 900px・右に端末の一覧・押した方が右に出る・Esc/暗い所で設定画面ごと閉じる、800×700 では幅 720px（9割）を確かめた。400×760・760×400・1024×560・680×1000 では1列で、一覧は全画面で出て「閉じる」で設定画面に戻ることを確かめた
  - 1024×768 の画面を撮って見た目を確かめた（左に設定の行、右に一覧が並ぶ）
- 本人が見るべき点
  - 右に出ている方の「一覧」ボタンはテーマの選択と同じ強調色になる。印として紛らわしければ変える
  - 右の一覧の帯には「閉じる」が無い（設定画面の「閉じる」で一緒に閉じる）
  - 実機（iPad）では未確認。`make install` して palmterm を再起動してから確かめてほしい
