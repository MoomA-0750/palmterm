# ログイン用 URL を使い捨てにする

## 目的
ログイン用 URL を使い捨てにする

## 完了の条件
- [ ] 確かめる手順: palmterm url を打つたびに、新しいトークンの入った URL と QR コードが出る
- [ ] 確かめる手順: その URL を開くと、端末名の入力欄と「ログイン」ボタンのページが出る（設定の言語で）。入力欄には自動の名前（例「iPhone · Safari」）を薄く出しておく。開いただけではトークンを使わず（リンクのプレビューに使い切られない）、同じ URL をもう一度開いても同じページが出る
- [ ] 確かめる手順: 名前を入れてボタンを押すとログインし、端末の画面に移る。「ログイン中の端末」の一覧にはその名前で出る（40 文字まで、前後の空白と制御文字は除く）。空のまま押せば自動の名前になる。そのあと同じ URL を開いてボタンを押しても、ログインできない
- [ ] 確かめる手順: 出してから5分たった URL ではログインできない
- [ ] 確かめる手順: 起動時の案内（ログ）にも使い捨ての URL を出す
- [ ] 確かめる手順: 固定のトークン（token ファイルの中身、-token）ではログインできない。-token はなくなる
- [ ] 確かめる手順: 更新前からログインしていた端末は、ログインし直さずにそのまま使える
- [ ] 確かめる手順: palmterm を再起動すると、まだ使っていないトークンはすべて無効になる
- [ ] Go のテストで上の1〜8を確かめ、make test が通る。SPEC.md の「ログインと安全」と README を、今の動きに書き換える
