# 設定画面の「通知」と「キーバー」の行をトグルスイッチにする

## 目的
設定画面の「通知」と「キーバー」の行をトグルスイッチにする

## 完了の条件
- [ ] 確かめる手順: 設定画面の「通知」の行が、文字のボタン（「オンにする」「切る」）ではなく、トグルスイッチ1つで出る。切れているときに押すと許可を求め、オンになるとスイッチがオンの位置になる。オンのときに押すと切れて、切れた位置に戻る
- [ ] 確かめる手順: 許可を待っている間や登録している間は、通知のスイッチを押せない（二重に押せない）。許可されなかったり失敗したりしたら、切れた位置に戻る
- [ ] 確かめる手順: 通知を使えないとき（ホーム画面から開いていない・HTTPS でない・未対応・拒否された）は、スイッチを押せない薄い形で切れた位置に出し、理由の文を添える
- [ ] 確かめる手順: 設定画面の「キーバー」の行も、文字のボタン（「隠す」など）ではなくトグルスイッチ1つで出る。キーバーが出ているときはオンの位置で、押すとキーバーが隠れて切れた位置になり、もう一度押すと出てオンの位置に戻る
- [ ] 単体テストと通しのテストで上を確かめ、make test が通る

## 結果
- 何をしたか
  - 設定画面の「キーバー」と「通知」の行を、文字のボタンからトグルスイッチ1つ（`<button role="switch" aria-checked>`、クラス `settings-switch`）に替えた（web/src/settings.ts、style.css、i18n.ts）
  - キーバー: 出ていればオンの位置。押すと隠れて切の位置になり、もう一度押すと出てオンの位置に戻る
  - 通知: 切の位置で押すと許可を求め、登録できたらオンの位置に動く。オンの位置で押すと切れて切の位置に戻る。許可を待つ間・登録する間、それと設定画面を開いて今の様子が分かるまでは押せない。断った・決めなかった・失敗したときは切の位置に戻る（失敗したときは理由を添え、押し直せる）。使えないとき（ホーム画面から開いていない・HTTPS でない・未対応・拒否された）は、押せない薄いスイッチを切の位置に出し、理由の文を添える
  - 「オン」の文字と「オンにする」「切る」「隠す」「出す」の文言はやめた。スイッチの名前は状態で変えず、「キーバーを出す」「この端末で palmterm notify の知らせを通知で受ける…」に固定し、状態は aria-checked で示す（理由は docs/decisions.md）
  - SPEC.md の「キーバー」と「画面を閉じている端末への通知」の項目を今の動きに書き換えた
- どう確かめたか

  - 通しのテスト「設定画面でキーバーのスイッチを切ると端末が広がり…」と「設定画面の「通知」の行は…」（web/e2e/app.test.ts）を、スイッチの位置（aria-checked）と押せるかで確かめるように直した
  - `make test` が通った（Go のテスト、単体テスト 168件、通しのテスト 46件）。1回目と2回目は落ちた（メモを参照）
