# 設定画面の「通知」と「キーバー」の行をトグルスイッチにする

## 目的
設定画面の「通知」と「キーバー」の行をトグルスイッチにする

## 完了の条件
- [ ] 確かめる手順: 設定画面の「通知」の行が、文字のボタン（「オンにする」「切る」）ではなく、トグルスイッチ1つで出る。切れているときに押すと許可を求め、オンになるとスイッチがオンの位置になる。オンのときに押すと切れて、切れた位置に戻る
- [ ] 確かめる手順: 許可を待っている間や登録している間は、通知のスイッチを押せない（二重に押せない）。許可されなかったり失敗したりしたら、切れた位置に戻る
- [ ] 確かめる手順: 通知を使えないとき（ホーム画面から開いていない・HTTPS でない・未対応・拒否された）は、スイッチを押せない薄い形で切れた位置に出し、理由の文を添える
- [ ] 確かめる手順: 設定画面の「キーバー」の行も、文字のボタン（「隠す」など）ではなくトグルスイッチ1つで出る。キーバーが出ているときはオンの位置で、押すとキーバーが隠れて切れた位置になり、もう一度押すと出てオンの位置に戻る
- [ ] 単体テストと通しのテストで上を確かめ、make test が通る
